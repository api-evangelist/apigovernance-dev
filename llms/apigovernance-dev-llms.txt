# APIGovernance.Dev

> APIGovernance.Dev is an AI-powered API governance product from PerfAI, Inc. that
> automates API design reviews against the "API Governance Top-10 List", a curated set of
> best practices the vendor says was trained on 10,000 public APIs. It is sold as a hosted
> SaaS with CI/CD, API gateway, Jira and GitHub Issues integration.

Generated by API Evangelist on 2026-09-04 from the public apigovernance.dev site and the
artifacts in this repository. This file is written BY API Evangelist ABOUT APIGovernance.Dev;
it is not published by PerfAI, Inc. Nothing here was obtained with credentials.

## Status — read this first

APIGovernance.Dev is a LEGACY product. Its parent, PerfAI, Inc., now trades as Perfai
Security and its own https://perfai.ai/llms.txt states that the earlier API performance,
governance and privacy positioning "is outdated" and asks readers to disregard it. The
apigovernance.dev marketing site is still served and still lists purchasable plans, but the
application host it sends buyers to, app.apigovernance.dev, did not answer on port 443 when
probed on 2026-09-04. Treat any integration plan against this product with caution and
confirm with the vendor first. Detail: lifecycle/apigovernance-dev-lifecycle.yml

## API surface

APIGovernance.Dev publishes NO public API. There is no developer portal, no API reference,
no OpenAPI, AsyncAPI, GraphQL SDL, Postman collection, MCP server or agent card on any host
this record knows. Probed 2026-09-04: /openapi.json, /openapi.yaml, /swagger.json,
/v1/openapi.json, /api-docs, /docs, /redoc, /llms.txt, /robots.txt, /sitemap.xml and the
full /.well-known/* set all return HTTP 404 on apigovernance.dev. There is no API base URL
to record. The product is consumed through its web application and its CI/CD integration,
not through a published contract.

The Perfai Security API at https://api.perfai.ai/v1, documented at https://docs.perfai.ai,
belongs to the successor product and is NOT this company's API. Do not call it as
APIGovernance.Dev.
